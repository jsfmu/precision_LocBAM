# Calibration confirmation plan (written before any confirmation data exists)

Date frozen: 2026-11-24 · code at commit `7fc8051` plus the uncommitted changes that add this file.

## Why a confirmation run
Every calibrator after the original global temperature was chosen after looking at results on the
49 test patients of the fold-0 held-out set. Those results are exploratory. This run tests the chosen
calibrator once, on patients that nothing in this project has used, with nothing refitted.

## Confirmation set
The 316 KiTS23 cases that the fold-0 checkpoint never used: not trained on (64), not used for
model selection (8), and not in the 97-case held-out fold used for calibration fitting and exploration.
Generated by `make_kits_local_split.py` (seed 0, fold 0); the 4 corrupted cases stay excluded.
All 316 are evaluated; none is dropped after seeing results. A case that fails to load or run is
reported as a failure with its id.

## Hypotheses (whole-volume and organ-region metrics as defined in `evaluate_calibration.py`)
All comparisons are against the raw model (T = 1), pooled over the 316 patients, with 95%
paired patient-bootstrap intervals (1000 resamples, seed 0). "Confirmed" = interval of the change
excludes 0 in the stated direction.

**Primary**
- H1: the primary calibrator lowers whole-volume NLL.

**Secondary** (reported whatever the outcome; no correction for multiplicity, read as supporting evidence)
- H2: lowers organ-region NLL.
- H3: lowers whole-volume Brier score.
- H4: lowers organ-region top-label ECE.
- H5: lowers organ-region tumor ECE.
- H6: lowers organ-region kidney ECE.
- H7: argmax Dice for kidney, tumor and cyst is identical to the raw model (mathematical check, asserted in code).

**Original planned calibrator** (global T = 0.947, `temperature.json`)
- Reported on the same metrics. Expectation from the exploratory data: no improvement in whole-volume
  NLL and worse organ-region NLL. Either outcome is reported.

## What would count against the claim
H1 not confirmed, or H2 changing sign, means the improvement seen on the exploratory test patients
did not generalize, and the write-up says so.

## Procedure
1. `cache_logits.py --checkpoint <checkpoint> --fold-json data/kits_json/kits_fold0_unused.json
   --patch-size small --preprocessing coords --out-dir data/cache_confirm`
   (same settings as the exploratory cache: patch 32³, sw batch 128, overlap 0.25, constant blending).
2. `data/cache_confirm/851c43ca5339/` holds copies of the two frozen calibrator files (hashes above,
   checked before evaluating) and a `split.json` with all 316 cases as test, no calibration cases.
3. `evaluate_calibration.py --cache data/cache_confirm/851c43ca5339
   --calibrators temperature.json calib_pred8_predclass.json --plots`, run once.
4. No calibrator is fitted, chosen or tuned on these cases. Any later analysis on them is labelled exploratory.
